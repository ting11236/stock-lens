# 今日市場摘要更新

每日發布於行情、融資更新後執行 `market_summary.py`，再由靜態頁產生器把摘要直接放入首頁。訪客不需下載行情資料包。行情採最近已取得的交易日，頁面明示日期與上市範圍。

產業漲跌使用證交所各產業價格指數（排除綜合、槓桿和反向指數），不是成分股簡單平均。成交集中度使用本站同日上市股票的官方成交金額，不含 ETF、存託憑證與權證，不稱淨流入。融資僅使用相同日期；缺收盤價的估算仍標示 ≥，不宣稱確定跌破150%。

加權指數單日變動達3%會自動提示大幅波動，這是本站觀察門檻。重大事件的背景由研究查證後填入 `research/market-summary-events.json` 的 `events`。每筆需有 `status: reviewed`、`date`、`valid_until`（最長7天）、`title`、`summary`、`source`（https）；事件依摘要交易日生效，過期自動移除。不得憑股價猜測原因。初始沒有未經查證的新聞。

行情日期或欄位不符時保留原有效摘要，標示更新狀態；各區數字不混用不同日期。來源可在首頁詳細數字中查看。
