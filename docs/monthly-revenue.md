## 官方來源與使用限制

採用 [上市公司每月營業收入彙總表（18420）](https://data.gov.tw/dataset/18420)，免費、政府資料開放授權條款第 1 版。實際使用 [TWSE OpenAPI](https://openapi.twse.com.tw/v1/opendata/t187ap05_L)；資料集官方另列 [CSV](https://mopsfin.twse.com.tw/opendata/t187ap05_L.csv)。名冊用 [t187ap03_L](https://openapi.twse.com.tw/v1/opendata/t187ap03_L)。保留來源並說明本網站作了單位換算與 TTM 檢查。

開放 API 只提供「當月」「上月」「去年當月」及累計收入，沒有任意歷史年月參數。這些三個單月欄有明確月份，可保留，但不能當成連續歷史。原值千元轉為 TWD 元；2026-08 台積電 514,805,337 千元轉為 514,805,337,000 元，與官方投資資訊中心的單月元值一致。

研究過 MOPS 靜態歷史 CSV `https://mops.twse.com.tw/nas/t21/sii/t21sc03_115_8_0.csv` 與 `114_8_0.csv`；均回傳 HTTP 200 的「因為安全性考量…無法呈現」HTML，未將其當作 CSV，也未繞過限制。

[TWSE 投資資訊中心](https://www.twse.com.tw/IIH2/zh/company/financial.html?code=2330) 網頁使用 `/rwd/zh/IIH/company/financial?code=2330`，台積電回應含 13 個月元值；但 [TWSE 使用條款](https://www.twse.com.tw/zh/terms/use.html)「下載軟體或資料」禁止非同意方式之自動化下載，而此網站資料未確認在上述開放授權範圍內。因此沒有納入批次擷取器，沒有自動抓取 PDF、替換主機來繞過阻擋、付費方案或 API 金鑰。

完整歷史回補仍需要官方提供有明確開放授權的歷史下載介面，或證交所對該介面自動取得及公開展示的同意。尚未索取或取得額外同意。這不是使用者點一次「同意」就能代替官方授權的問題。

## 口徑與 TTM

每筆有代號、當時來源名稱、營收月、原始字串／千元、TWD 元值、未知合併／個體口徑、來源欄位與來源資料月、出表日、下載時間、公告日 null 與原因。出表日明確另存 `table_date`，不冒充公司公告日。

TTM 以所選截止月往前**連續 12 個月**加總；任一月缺值、未知／不一致口徑、公司身分不一致／未驗證、不同幣別或修訂冲突都拒算。零是真實數值，負營收亦不擅自改零。最新披露截止月過期仍可保存歷史 TTM，但畫面突出起迄及過期提醒。前端按台灣年月重新判斷過期，不會因重新整理而把舊資料視為當月。

公開資料未逐列標示合併／個體，現有记录為 `basis=unknown`。不得僅根據公司代號相同就認定歷史身分相同：上月／去年同月的 `identity_verified=false`，紀錄保留查核線索，不能拼接計算。累計數不能單独推導出所有月份；缺乏完整同口徑相鄰 YTD 及身分驗證，原型不反推單月。

## 保存、更新及失敗

`revenue-history.json` 是持久資料，逐月不清除，後續持續保存 24 個月以上。相同版本不改下載時間。直接當月欄修訂時更新該記錄，舊版本存 `revisions`；比較欄若和原當月值不同則存 `comparison_conflicts`，保留原值並拒算，等待查核，不默默覆蓋原月份。CSV 提供當前紀錄，JSON 可下載修訂版本。

沿用每天 18:20 工作流程。每輪只取一次全市場名冊、一次全市場月營收（沿用至多三次、退避重試、40 秒 timeout、大小上限），不每天重抓全歷史或逐家公司 1,089 個請求。全市場批量回應解析後先驗證涵蓋率 >=90% 且名冊沒有异常縮水，再原子保存，來源失敗保留歷史及 CSV、發布失敗狀態，Actions report 失敗。部分公司缺值是明列限制，不讓整站無法載入。初次失敗輸出空 JSON 和 CSV。

依 [月營收申報規定](https://twse-regulation.twse.com.tw/TW/law/DAT08_print.aspx?FLCODE=FL067432)，一般每月十日前申報，115 年起保險業及具保險業子公司的公司可延至十五日。因此資料月過期提醒採十六日保守門檻，沒有宣稱 API 固定分鐘完成或一定已公告。開放資料集所列「每1年」更新頻率和月營收概念不一致，並未將其當作固定公布 SLA。
