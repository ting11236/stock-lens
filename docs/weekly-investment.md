# 每週 AI 產業與台股投資分析

本專欄由獨立研究對話維護，不改全市場資料更新配額。首頁「最近夯什麼、不夯什麼」旁新增紫色按鈕；點開原生dialog。報告上方以總覽、產業Top5及逐股按鈕切換；一次只顯示一檔，例行資料收合。每檔先列左／右側階段、按兵不動或條件式30%／30%／40%目標部位建倉、訊號、信心與失效。產業名單連結 `./?company=代號#detail`，由本專欄接回既有個股資訊，不修改主程式。獨立入口為 `weekly-investment.html`。

## 資料與所有權

- 本專欄擁有 `site/weekly-investment.*`、`site/data/weekly-investment.json`、`site/data/weekly-investment/*`、`research/weekly-investment/*`。
- `index.html` 只增入口、資源載入與獨立dialog，既有事件ID、導航、Chart及資料不動。
- 例行財報／法說採既有網站資料及來源簡述；專欄重點在價格／買訊／信心／失效。重要口徑衝突才另核。各數值仍帶實際期間，缺值不猜。
- JSON內 fact/company_forecast/institution_forecast/research_inference 分開。TTM與Forward PE分開；Forward必須有提供者、發布日、年度及涵蓋。公開轉載的歷史EPS誤列淨利時不採該欄。
- 週版本不可覆蓋，修正新增v2；當前指標檔由原子replace更新。研究、網站驗證、發布為不同紀錄，研究partial可以公開但不能宣稱完整。

## 價格與新鮮度

以TWSE各日成交資訊，收盤為最近完成交易日；5/10/20/60均線為相同口徑收盤算術均值，20日均量為此前20交易日、不含當日。未還原現金股息不是含息報酬。跨重大除權而未完成調整時保留缺值，不用錯的60日均線和EPS產生價格。

觀察價為技術支撐壓力與明示研究倍數的交集，不是確定報酬、價格預測或下單指令。買訊須同時有價量與基本面確認。沒有交集／證據則null。頁面在到期、新交易日盤後未刷新或可能過期時顯示等待核對。

## 續做與排程

排程由本地Codex heartbeat沿用此對話每天Asia/Taipei 13:30、21:30。週一建立新week_id；同週其他機會只接未完／重大變化。原研究每天補齊排程保持不變。關機錯過時下次承接，不假設關機可執行。

共用正式狀態在 `/Users/ting/Documents/Codex/台股研究交接/每週投資決策/` 的 weeks、daily 與發布鎖。task_id固定 `weekly-ai-tw-investment`；update_id為週＋版本。同日第二輪不得重寫首版。未變更不更新reviewedAt。

發布前取得共用檔案／發布時段，讀最新main，刷新官方價格，檢驗欄位／來源／權重／過期狀態／響應式UI。僅提交本專欄範圍，依現有main GitHub Actions Pages流程，不夾帶既有本機未提交修改。部署成功與正式URL可讀後再寫published；失敗保留可檢查版本與待辦。通知僅交付、重大變化、失敗或需要使用者處理。

產業Top5的關鍵字可點擊，以 `./?search=關鍵字#listTitle` 回主表格搜尋；主頁內可直接關閉報告並沿用既有搜尋。這是網站內容關鍵字命中，不是已驗證純產業供應商名單。

從報告跳到搜尋或個股後顯示固定「回上一頁」按鈕，重開原報告頁籤並恢復捲動位置。直接從獨立報告連結進首頁則回產業Top5頁籤。
