## 衍生指標

逐季保存一般業損益及權益。對 Q1–Q3，TTM = 上年全年 + 本年累計 − 上年同期累計；Q4 直接使用全年。任何必要數值缺少就不算，不將半年乘二。

- **PS** = 股價 × 官方已發行普通股數 ÷ TTM 營收。營收千元先乘 1,000；保留股價日、股數出表日和財報期間。
- **EPS 成長** = (TTM EPS ÷ 上年同期間 TTM EPS − 1) × 100。兩組 EPS 須為正。不是營收年增、不是單季年增。
- **歷史 PEG** = (股價 ÷ TTM EPS) ÷ EPS 成長百分點。累計與 TTM EPS 須正值，成長須 1–100%，排除極小或極大成長基期。此上限是可調整的研究保護條件，不是市場標準。保留計算 PE 與比較期間；不冒充預估 PEG。
- **ROE** = TTM 歸屬母公司淨利 ÷ 同口徑期初期末平均母公司權益 × 100。期初期末權益須正值。金融特殊報表尚未納入推算。

第一次只有最新季資料，通常無 PS／ROE／TTM EPS 成長／PEG。完整歷史尚未回補；系統會逐期累積，或可由具展示授權的 CSV 補充。拆併股、重編與報表口徑變動可能使歷史不具可比性，需人工核對。TradingView／Investing.com 只提供查核連結，不自動擷取。

## 更新一致性

每次先在記憶體驗證核心資料，失敗不覆寫快照。JSON／CSV 在全部內容計算完成後原子替換各檔；GitHub Pages 以同一 artifact 整體發布。相同值、期間、來源不刷新取得時間；來源嘗試時間留於 Actions 日誌。失敗狀態獨立於股票資料保存，因此舊行情不因失敗時間戳被假裝更新。

歷史 PEG 優先採 5 年、其次 3 年全年 EPS CAGR。5 年需要 6 個連續年度、3 年需要 4 個連續年度，所有 EPS 須正值且報表口徑相同。CAGR = [(期末 EPS / 起始 EPS)^(1 / 年數) − 1] × 100%；PE = 最新股價 / 期末全年 EPS；PEG = PE / CAGR 百分點。2020–2023 年 EPS 補自 MOPS ajax_t163sb04（TYPEK=sii、年度為民國、season=04），存各年度來源和查閱日期。歷史年度資料未逐家追溯調整 IFRS17、股數及重編差異；不同年份 PEG 須同口徑比較。

CAGR 不足時才採兩組可比 TTM EPS；再不足時以最新完整年度和前一年度 EPS 計算年增率。各方式均標示比較期間、計算方法及股價日期，PEG 沿用 1%–100% 成長範圍，超出範圍仍顯示成長率而不列 PEG。這些是歷史資料，不是未來預估。

資產負債以臺灣上市公司營運研究_202610033.numbers 的「資產負債來源」為原始期末金額（億元），保留報表日、合併／個別基礎、原財報來源及現金流期間。負債比 = 總負債 / 總資產；流動比率 = 流動資產 / 流動負債；現金覆蓋 = 現金及約當現金 / 流動負債；母公司權益成長以同年度前一年年底為基期。分母缺值或非正不計算；零現金保持零。所有負債包含應付款項，不等於借款；表列借款及債券不視為完整淨負債。金融業不套一般業流動比率判斷。

market_movers.py 使用 TWSE MI_INDEX 每日全市場收盤表，驗證回傳交易日期及至少 500 家四碼股票，保留最近 65 個交易日。1 日用官方漲跌比較基準；5／20 日必須有 n+1 個交易日且每一日均有成交資料，不比較日期不同、無成交或特殊參考價的股票。多日漲跌 = (期末收盤 / 起始收盤 − 1) × 100%，未還原除權息、並非含息報酬。漲跌分開取前十名，族群只統計官方產業，不推論原因。每日發布時更新；來源失敗保留舊資料與原日期。

## 公司會議與摘要更新清單

`company_calendar.py` 每日讀取公開資訊觀測站法說會一覽表（前一月至未來兩月）、證交所股東會公告 t187ap38_L 及每日重大訊息 t187ap04_L。多日場次保留日期區間；摘要提供逐場日期時才拆成個別場次。取消場次不列未來日程；來源失敗保留已有日期並標示部分來源失敗。首次部署可使用 research/company-calendar-seed.json 中已取得的官方公告。

會議結束翌日列入摘要更新清單，重大訊息與新月營收／財報期間也可觸發待辦。摘要查核日期晚於事件或新資料偵測日才清除待辦，同日查核不自動假定已讀完會後文件。日程與清單自動更新；文字摘要需要讀取來源後另外整理。金融資料期間變化以每日快照的欄位 metadata 判斷，首次載入建立基準，不把全市場舊數字當作剛公告。

近一週漲跌幅使用最近 5 個交易日的起訖收盤價，完整比較資料涵蓋所有有效股票，不限漲跌榜上公司。股價日期必須等於比較期末；資料缺漏或特殊比較基準時保留缺值。未還原除權息。
