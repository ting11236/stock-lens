官方資料與交易日期

每日台灣時間 18:20 由 GitHub Actions 下載臺灣證券交易所開放資料，依上市公司名冊合併。範圍為上市公司四碼普通股（含創新板與外國第一上市公司）；不含上櫃、ETF、權證、特別股及 TDR。

股價、PE／PB 的 Date 是各自的資料日期；下載時間另行記錄。財務資料使用財報年季或營收年月。官方只公布更新頻率，沒有保證每日固定完成時刻；排程也可能延後。

各項指標的口徑

收盤價：STOCK_DAY_AVG_ALL。PE、PB、殖利率：BWIBBU_ALL。累計基本 EPS：t187ap14_L。單月營收年增率：t187ap05_L。累計毛利率：t187ap17_L。

一般業財報 t187ap06_L_ci／t187ap07_L_ci 逐期保留歷史。完整期間累積後才計算 TTM EPS、EPS 年增率、PS、ROE 與歷史 PEG。初次使用通常沒有足夠歷史，因此顯示 —。財報千元轉元後才計算 PS，ROE 使用母公司口徑的平均權益。

歷史 PEG 使用自行計算的 PE（股價 ÷ TTM EPS）除以 TTM EPS 年增率百分點。兩期 EPS 須正值，年增率須在 1%–100%；此保守門檻是研究規則。它可能與官方 PE 口徑不同，並非預估 PEG。

個人自選與人工分類

在全部股票搜尋代號或公司名稱，按星號即可加入／移除。自選清單與人工分類存在此瀏覽器的 localStorage；重新整理會保留，每次開啟仍重新下載最新雲端資料。不同裝置不會同步；共用同一瀏覽器設定檔會共用清單。

CSV 至少需要 symbol 欄位，例如 2330 或 2330.TW；category 可選填。匯入會合併自選清單，保留人工分類，但不會用匯入股價覆蓋官方資料。完整數值可從自選或全部股票 CSV 匯出。

缺值、舊資料與查核

主要資料來源更新失敗時，保留整份有效快照，並發布失敗狀態。部分財務來源失敗時保留已有欄位，標示舊值。若排程本身停止，網站會依股價日期提示可能過期；國定假日可能觸發提醒，請核對官方開休市日曆。

TradingView 與 Investing.com 是個股明細中的人工查核入口；本站不爬取兩站資料。每個欄位的資料期間、來源、下載時間與缺值原因都可展開查看。
