自動網路快照

雲端排程預設每天台灣時間 18:20執行，完成後發布本站的每日 JSON 快照。網站本身是靜態網頁，不需要你安裝 Python。預設使用 TWSE 政府開放資料更新上市台股的收盤價、PE 和 PB；PS、PEG、美股、上櫃股票等需另外接入合法授權 CSV 資料來源。缺漏數字不會自行補值。若取得失敗，保留原有成功資料並顯示新舊時間。

輸入四碼台股會轉為 .TW；上櫃請明確輸入 .TWO；美股直接輸入英文代號。價格時間與財報期間未必相同，請到來源頁再次確認。

TradingView / Investing.com 交叉查核

個股明細附有 TradingView 圖表與 Investing.com 搜尋入口，供你人工比較 PE / PB / PS / PEG。兩站的自動擷取受條款限制，因此本版不會假裝是從兩站直接取得指標。

你可以手動整理／合法匯出 CSV，再從網頁匯入，原始倍數將原樣保留。自行新增的股票與手動調整只保存在目前瀏覽器；要讓新股票每天雲端更新，請在網站專案的 watchlist.json 新增代號並發布。不同網站的 PE（TTM／預估）、PS（TTM）、PB（最近淨值）、PEG（歷史／預估成長）定義可能不同。

資料格式

CSV 欄位：symbol, name, category, industry, price, currency, pe, pb, ps, peg, gross_margin, revenue_growth, earnings_growth, roe, trailing_eps, net_income, source。

所有百分比輸入百分點，例如 72 代表 72%；倍數輸入純數字 0.8，而非 0.8x。未填的欄位保持空白，不會填上教學數字。

分類與估值限制

分類以金融優先、實際虧損次之，再依成長與產業判斷高成長／週期／穩定獲利；可以逐檔手動覆寫。PEG 需確認成長率口徑，PS 應配合毛利與現金流，PB 要看 ROE 與資產品質。

沒有產品營收的生技公司，PS 往往不具比較性；高週期公司的低 PE 也可能是景氣高峰而非便宜。這裡只呈現研究提示，並非自動買賣建議。
